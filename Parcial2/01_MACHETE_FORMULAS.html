Machete de fórmulas — Parcial 2 (guías 06 a 09)

Los 3 errores que hacen perder más puntos:
1. Confundir n (subintervalos) con la cantidad de puntos: con n+1 puntos hay n subintervalos.
2. Usar Simpson 1/3 con n impar (no se puede) o 3/8 con n que no es múltiplo de 3.
3. En EDO, olvidar que cada método usa su pendiente: Euler la del principio, punto medio la del medio, Heun el promedio.

GUÍA 06 — Splines (interpolación segmentaria)

Con n+1 puntos hay n tramos. En cada tramo vale un polinomio distinto. Notación: h_i = x_(i+1) − x_i.

Spline lineal

S_i(x) = y_i + m_i (x − x_i) m_i = (y_(i+1) − y_i) / h_i Continuo, pero la DERIVADA SALTA en los nodos (la curva tiene picos).

Spline cuadrático

S_i(x) = a_i + b_i (x − x_i) + c_i (x − x_i)² Condiciones: a_i = y_i ; a_i + b_i h_i + c_i h_i² = y_(i+1) ; b_i + 2 c_i h_i = b_(i+1) Falta una condición: se toma c_1 = 0 (el primer tramo es una recta) Después, hacia adelante: c_i = (y_(i+1) − y_i − b_i h_i)/h_i² b_(i+1) = b_i + 2 c_i h_i

Spline cúbico — el que más se pide

Incógnitas: las segundas derivadas en los nodos, S''(x_i). Para cada nodo interior i:

h_(i−1) S''(x_(i−1)) + 2(h_(i−1) + h_i) S''(x_i) + h_i S''(x_(i+1)) = 6 [ (y_(i+1) − y_i)/h_i − (y_i − y_(i−1))/h_(i−1) ] Ese sistema es TRIDIAGONAL → conviene resolverlo con Thomas, O(n).

Condiciones de borde:

TipoCondiciónEcuaciones que se agregan
NaturalS''(x₀) = S''(xₙ) = 0Salen del sistema (quedan n−1 ecuaciones)
Sujeto (condicionado)Se dan S'(x₀) y S'(xₙ)2h₀S''₀ + h₀S''₁ = 6[(y₁−y₀)/h₀ − S'(x₀)]
h_(n−1)S''_(n−1) + 2h_(n−1)S''ₙ = 6[S'(xₙ) − (yₙ−y_(n−1))/h_(n−1)]

Con las S'' ya resueltas, los coeficientes de cada tramo:

a_i = y_i b_i = (y_(i+1) − y_i)/h_i − h_i (2 S''_i + S''_(i+1)) / 6 c_i = S''_i / 2 d_i = (S''_(i+1) − S''_i) / (6 h_i) S_i(x) = a_i + b_i(x − x_i) + c_i(x − x_i)² + d_i(x − x_i)³
Para justificar en la hoja: el spline tiene S, S' y S'' continuas en los nodos; el polinomio interpolante único de grado n oscila entre los nodos (fenómeno de Runge). Por eso con muchos puntos se prefiere el spline.

GUÍA 07 — Integración: trapecio y Simpson

h = (b − a)/n  ·  x_i = a + i·h  ·  n = subintervalos, hay n+1 puntos.

Trapecio

SIMPLE (n = 1): I = (b − a) [ f(a) + f(b) ] / 2 COMPUESTO: I = h/2 [ f(x₀) + 2(f(x₁) + f(x₂) + … + f(x_(n−1))) + f(xₙ) ] pesos: 1 2 2 … 2 1 Error: Et = −(b−a) h²/12 · f''(ξ) = −(b−a)³/(12 n²) · f''(ξ) → O(h²)

Simpson 1/3 — n tiene que ser PAR

SIMPLE (n = 2): I = h/3 [ f(x₀) + 4 f(x₁) + f(x₂) ] COMPUESTO: I = h/3 [ f(x₀) + 4(impares) + 2(pares interiores) + f(xₙ) ] pesos: 1 4 2 4 2 … 4 1 Error: Et = −(b−a) h⁴/180 · f⁗(ξ) → O(h⁴)

Simpson 3/8 — n múltiplo de 3

SIMPLE (n = 3): I = 3h/8 [ f(x₀) + 3 f(x₁) + 3 f(x₂) + f(x₃) ] COMPUESTO: pesos: 1 3 3 2 3 3 2 … 3 3 1 Error: mismo orden que 1/3, O(h⁴)

n IMPAR: hay que combinar

Simpson 1/3 en los primeros n−3 subintervalos (cantidad par) Simpson 3/8 en los últimos 3 I = I(1/3) + I(3/8)

Cuántos subintervalos para una tolerancia

Trapecio: n ≥ raíz( (b−a)³ · max|f''| / (12 · tol) ) Simpson 1/3: n ≥ ( (b−a)⁵ · max|f⁗| / (180 · tol) )^(1/4) Se redondea SIEMPRE para ARRIBA (y al primer par si es Simpson 1/3).
Para estimar el error cuando NO dan el valor exacto: se usa la derivada promedio, que sale exacta con el teorema fundamental:
f'' promedio = [ f'(b) − f'(a) ] / (b − a)  y  f⁗ promedio = [ f'''(b) − f'''(a) ] / (b − a).
Con el máximo de la derivada se obtiene una cota del error.

Extrapolación de Richardson

Sobre un método O(h²): D = [ 4 D(h/2) − D(h) ] / 3 (queda O(h⁴)) General para orden p: D = [ 2^p D(h/2) − D(h) ] / (2^p − 1)
Pregunta clásica: ¿qué pasa si h es muy chico? El error de truncamiento baja, pero el de redondeo sube: al restar f(x+h) − f(x−h), dos números casi iguales, se pierden cifras significativas, y después se divide por un h chiquito, que amplifica el ruido. Hay un h óptimo. Es al revés que en integración, donde bajar h casi siempre mejora. (Epsilon de máquina: 2.22·10⁻¹⁶.)

Cómo se verifica el orden (pregunta típica): se resuelve con h y con h/2 y se compara el error. Si el método es de orden p, el error se divide por 2^p: por 2 en Euler, por 4 en Heun/punto medio, por 16 en RK4.
Diferencia entre Heun y punto medio: los dos son de orden 2, pero Heun promedia las pendientes de los dos extremos del intervalo, y punto medio usa una sola pendiente, la del centro. Heun se puede iterar el corrector; punto medio no.

Otro esquema de Runge-Kutta (lo tomaron en 2025)

Cualquier RK se describe con sus coeficientes. El esquema general:

k1 = f(xi , yi) k2 = f(xi + a2·h , yi + b21·h·k1) k3 = f(xi + a3·h , yi + b31·h·k1 + b32·h·k2) k4 = f(xi + a4·h , yi + b41·h·k1 + b42·h·k2 + b43·h·k3) y(i+1) = y(i) + h·( w1·k1 + w2·k2 + w3·k3 + w4·k4 ) Control: w1 + w2 + w3 + w4 = 1 (si no da 1, el método no es consistente)

EDO de orden superior → bajar a primer orden

Euler y RK4 solo resuelven ecuaciones de primer orden. Si te dan una de segundo orden, lo PRIMERO es el cambio de variable:

Dada: y'' = g(x , y , y') con y(x0) = y0 , y'(x0) = y'0 Se define: z = y' Queda el SISTEMA de dos ecuaciones de primer orden: dy/dx = z dz/dx = g(x , y , z) con y(x0) = y0 y z(x0) = y'0 Ejemplo: y'' + 2y' + 5y = 0 → dy/dx = z ; dz/dx = −2z − 5y
El error más común: avanzar una incógnita y después la otra. Las dos avanzan a la vez: hay que calcular k1y y k1z antes de pasar a los k2, porque la pendiente de cada una depende del valor de la otra.
RK4 para el sistema: k1y = z_i k1z = g(x_i , y_i , z_i) k2y = z_i + k1z·h/2 k2z = g(x_i+h/2 , y_i+k1y·h/2 , z_i+k1z·h/2) k3y = z_i + k2z·h/2 k3z = g(x_i+h/2 , y_i+k2y·h/2 , z_i+k2z·h/2) k4y = z_i + k3z·h k4z = g(x_i+h , y_i+k3y·h , z_i+k3z·h) y(i+1) = y_i + h(k1y + 2k2y + 2k3y + k4y)/6 z(i+1) = z_i + h(k1z + 2k2z + 2k3z + k4z)/6
